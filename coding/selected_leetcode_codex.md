## 2. Arrays

- **53. Maximum Subarray** — *Medium*: Given an integer array, find the contiguous subarray with the largest sum and return that sum.
- **238. Product of Array Except Self** — *Medium*: Return an array where each element is the product of all elements except itself. Solve in O(n) time without division.
- **448. Find All Numbers Disappeared in an Array** — *Easy*: Given an array of length n with values in [1, n], return the numbers in [1, n] that do not appear.

## 3. Hash Table

- **1. Two Sum** — *Easy*: Return the indices of the two numbers that add up to a given target (exactly one solution).
- **217. Contains Duplicate** — *Easy*: Return true if any value appears at least twice in the array.
- **560. Subarray Sum Equals K** — *Medium*: Return the total number of continuous subarrays whose sum equals k. Uses prefix sums + a hash map.

## 4. Two Pointers

- **125. Valid Palindrome** — *Easy*: Return true if a string is a palindrome, considering only alphanumeric characters and ignoring case.
- **15. 3Sum** — *Medium*: Find all unique triplets in the array that sum to zero; deal carefully with duplicates.
- **11. Container With Most Water** — *Medium*: Given an array of heights, find two lines that together with the x-axis form a container holding the maximum water.

## 5. Sliding Window

- **3. Longest Substring Without Repeating Characters** — *Medium*: Return the length of the longest substring without duplicate characters.
- **424. Longest Repeating Character Replacement** — *Medium*: Return the longest substring with all the same letters achievable after at most k replacements.
- **76. Minimum Window Substring** — *Hard*: Return the smallest substring of s that contains every character of t.

## 6. Strings

- **242. Valid Anagram** — *Easy*: Determine whether string t is an anagram of string s.
- **49. Group Anagrams** — *Medium*: Group strings that are anagrams of each other.
- **5. Longest Palindromic Substring** — *Medium*: Return the longest palindromic substring in the given string.

## 7. Stack & Queue

- **20. Valid Parentheses** — *Easy*: Determine whether a string of brackets is valid.
- **155. Min Stack** — *Medium*: Design a stack that supports push, pop, top, and retrieving the minimum element — all in O(1) time.
- **232. Implement Queue using Stacks** — *Easy*: Implement a FIFO queue using only two stacks.

## 8. Linked List

- **206. Reverse Linked List** — *Easy*: Reverse a singly linked list.
- **141. Linked List Cycle** — *Easy*: Detect whether a linked list has a cycle.
- **19. Remove Nth Node From End of List** — *Medium*: Remove the nth node from the end of a linked list in one pass.

## 9. Binary Tree / BST

- **226. Invert Binary Tree** — *Easy*: Mirror (invert) a binary tree.
- **104. Maximum Depth of Binary Tree** — *Easy*: Return the maximum depth of a binary tree.
- **98. Validate Binary Search Tree** — *Medium*: Determine whether a binary tree is a valid binary search tree.

## 10. Tree Traversal & Lowest Common Ancestor

- **94. Binary Tree Inorder Traversal** — *Easy*: Return the inorder traversal of a binary tree.
- **102. Binary Tree Level Order Traversal** — *Medium*: Return the level-by-level traversal of a binary tree.
- **236. Lowest Common Ancestor of a Binary Tree** — *Medium*: Find the lowest common ancestor (LCA) of two given nodes in a binary tree.

## 11. Heap / Priority Queue

- **215. Kth Largest Element in an Array** — *Medium*: Return the kth largest element in an unsorted array.
- **23. Merge k Sorted Lists** — *Hard*: Merge k sorted linked lists into one sorted linked list.
- **295. Find Median from Data Stream** — *Hard*: Design a data structure that supports adding numbers and finding the median.

## 12. Intervals

- **56. Merge Intervals** — *Medium*: Merge all overlapping intervals.
- **57. Insert Interval** — *Medium*: Insert a new interval into a set of non-overlapping sorted intervals and merge if necessary.
- **435. Non-overlapping Intervals** — *Medium*: Return the minimum number of intervals to remove so the rest are non-overlapping.

## 13. Binary Search

- **704. Binary Search** — *Easy*: Classic binary search on a sorted array; return the target's index or -1.
- **33. Search in Rotated Sorted Array** — *Medium*: Search for a target in a rotated sorted array in O(log n) time.
- **153. Find Minimum in Rotated Sorted Array** — *Medium*: Find the minimum element in a rotated sorted array.

## 14. Graphs

- **200. Number of Islands** — *Medium*: Count the number of islands in a 2D grid of '1's and '0's (BFS/DFS).
- **133. Clone Graph** — *Medium*: Deep copy an undirected graph.
- **207. Course Schedule** — *Medium*: Determine whether all courses can be completed given prerequisites (cycle detection / topological sort).

## 15. Union-Find (Disjoint Set)

- **547. Number of Provinces** — *Medium*: Return the number of connected components (provinces) among n cities given an adjacency matrix.
- **684. Redundant Connection** — *Medium*: Find the edge that creates a cycle and can be removed to turn the graph into a tree.
- **721. Accounts Merge** — *Medium*: Merge accounts that share common emails.

## 16. Trie

- **208. Implement Trie (Prefix Tree)** — *Medium*: Implement insert, search, and startsWith.
- **211. Design Add and Search Words Data Structure** — *Medium*: Support adding words and searching with the '.' wildcard.
- **212. Word Search II** — *Hard*: Find all words from a list that appear on a 2D letter board (Trie + backtracking).

## 17. Backtracking

- **78. Subsets** — *Medium*: Return all possible subsets of an array of distinct integers.
- **46. Permutations** — *Medium*: Return all possible permutations of an array of distinct integers.
- **39. Combination Sum** — *Medium*: Find all unique combinations that sum to a target, with unlimited reuse of each element.

## 18. Dynamic Programming

- **70. Climbing Stairs** — *Easy*: Return the number of distinct ways to climb n stairs taking 1 or 2 steps at a time.
- **198. House Robber** — *Medium*: Return the maximum money that can be robbed from houses without robbing two adjacent houses.
- **322. Coin Change** — *Medium*: Return the fewest number of coins needed to make a given amount.

## 19. Greedy

- **55. Jump Game** — *Medium*: Determine whether you can reach the last index given the maximum jump length at each position.
- **45. Jump Game II** — *Medium*: Return the minimum number of jumps to reach the last index.
- **763. Partition Labels** — *Medium*: Partition a string into as many parts as possible so each letter appears in only one part.

## 20. Bit Manipulation

- **136. Single Number** — *Easy*: Find the element that appears exactly once when every other element appears exactly twice.
- **191. Number of 1 Bits** — *Easy*: Count the number of set bits ('1' bits) in an unsigned integer.
- **338. Counting Bits** — *Easy*: Return an array where each ans[i] is the number of '1' bits in i for 0 <= i <= n.

## 21. Matrix (2-D Array)

- **73. Set Matrix Zeroes** — *Medium*: Set an entire row and column to zero whenever an element is zero; do it in place with O(1) extra space where possible.
- **48. Rotate Image** — *Medium*: Rotate an n x n matrix 90 degrees clockwise in place.
- **54. Spiral Matrix** — *Medium*: Return all matrix elements in spiral order.
